# 2026-09-16

## Theme: Pre-paint theme init for dark-mode ads (commit 32edd8b)

- **What**: Added an inline theme-init script to `src/index.html` `<head>`, before the AdSense loader.
- **Why**: AdSense auto ads adapt creatives to the page's `color-scheme` (set in `styles.css` off the
  `.dark` class). Until Angular hydrates, the SSR HTML was unstyled-light, so dark-mode users got a
  light flash **and** light ads in the pre-hydration window. The script applies the stored/system
  theme to `<html>` pre-paint, mirroring `ThemeService`.
- **Result**: Dark-mode users get dark ads and no theme flash from first paint. `ThemeService`
  re-applies the class on bootstrap from the same inputs, so no divergence.

## Links tab: edit flow, compact cards, day grouping (frontend of Task 24 backend rule)

- **What**: `/insiden` "Submitted Links" cards are now editable (author-or-admin via new pure
  `can-edit.link.util.ts`), the card layout went compact (favicon+domain+timestamp row,
  line-clamp-1 title, tight badges, no arrow footer), and approved links render under
  Today/Yesterday/date headers (new pure `link-day-group.util.ts`, UTC buckets so SSR and
  browser agree).
- **Why**: Non-admin edits must land back in the approval queue; admins' land live (backend
  role rule, backend-first). Links flood in — day headers + compact cards keep the list scannable.
- **How**:
  - `LinkSheetService` gained `editTarget` signal + `openEdit(link)`; `open()` resets it.
  - `LinkCardComponent`: `editable` input + `edit` output, absolute pencil button (sibling of
    the anchor so clicks don't navigate), explicit compact classes **without** `hlmCard` (see
    MISTAKES entry — Tailwind v4 cascade beats element-class overrides on the host directive).
  - `LinkFormComponent`: public `isEditing` computed; edit-mode hydration effect guarded by
    `_hydratedLinkId` (mirrors incident form); `submit()` branches to the UPDATE mutation
    (`UPDATE_SOCIAL_MEDIA_LINK_MUTATION` re-exported from `social-links.queries.ts`) with
    role-aware toasts; `clear()` resets `editTarget`.
  - `LinksSectionComponent`: `approvedGroups` computed, `canEdit(link)`/`openEdit(link)`,
    reload-on-sheet-close effect (drops appended pages + refetches page 1).
  - Page sheet labels switch to "Edit link"/"Save" via `linkFormRef()?.isEditing()`.
- **Tests**: `can-edit.link.util.spec.ts`, `link-day-group.util.spec.ts` (new), 6 edit-flow
  cases in `link-form.component.spec.ts`. Suite: 57 files / 436 tests green.
- **Gates**: `prettier --check` clean (feature dir), `npm run build` passes.

## Link form: pinned selections, parent-code chips, mandatory category dropdown

- **What**: Link submission UX tweaks (`LinkFormComponent` + shared `AssetMultiSelectComponent`):
  - Selected lines/vehicles/stations float to the top of their multi-select lists, returning to
    their original position on deselection (`pinnedSelected` opt-in input; off for incident form).
  - Vehicles/stations parent-line indicators render as chips showing only the code's last
    segment ("KTMK-PKL" → "PKL", "KTM ETS" → "ETS") with the full code on hover (`title`);
    `chipParentCodes` opt-in input + exported pure `parentCodeChipText()`.

    computed keeps the array mutation contract.

  carries a "Just Reporting" category. Suite: 58 files / 441 tests green.
