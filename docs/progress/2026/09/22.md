# 2026-09-22

## Home: community front page is now the landing route (commits de073ff, 0dc074f, ca8b495, f4ede6b)

- **What**: `src/app/features/home/` is the site's new landing page. The root `""` route previously
  redirected to `/spotting`; it now lazy-loads `HomePage` with route-scoped `HomeStore` and
  `LineStatusSheetService` providers (`src/app/app.routes.ts`). The page composes nav → submit box →
  global feed → per-line pulse list → footer, plus the line-status bottom sheet.
  - **Data layer** (`de073ff`): `data/home.queries.ts` — GraphQL documents + hand-written types
    (`FRONT_PAGE_LINES_QUERY`, `FEED_QUERY`, `SUBMIT_FEED_LINK_MUTATION`,
    `SUBMIT_LINE_STATUS_REPORT_MUTATION`, and the upvote/downvote/remove social-media-link vote
    mutations). `data/home.store.ts` — route-scoped `HomeStore` with two `graphqlResource`s (lines +
    feed), a `PollingSource` beat (`start()`/`stop()`), cursor pagination (`loadMore`, appended
    pages), `reloadAll()`, and an authenticated `userVote` overlay (`userVoteFor`/`setUserVote`)
    because `graphqlResource()` sends no auth token. `data/passenger-status.util.ts` —
    `PASSENGER_LABEL`/`PASSENGER_VARIANT`/`passengerLabel()` (null → "No data")/`passengerVariant()`.
    `data/line-status-sheet.service.ts` — open/close state for the status sheet.
  - **Line pulse + sheet** (`0dc074f`): `line-pulse/line-pulse-card.component.ts` (colour chip,
    `line-status-badge` operational status, `{inService} of {total} in service`, the passenger-status
    badge plus the consolidated `passengerStatusMessage`, up to 5 related `pulseLinks`, and a ≥44px
    "Submit line status" button) and `line-pulse/line-pulse-list.component.ts` (skeletons/empty
    state). `line-status/line-status-sheet.component.ts` — mobile bottom sheet with status chips,
    optional delay minutes + notes, a lazily-loaded station multi-select, submit →
    `submitLineStatusReport`; logged out it shows a login prompt.
  - **Feed** (`ca8b495`): `feed/link-submit-box.component.ts` — login-gated submit box (logged out:
    a clickable "Log in to submit links" button that triggers `AuthService.login()`; logged in: URL +
    optional `PassengerStatus` select + line multi-select + Submit, the duplicate indicator, and the
    record of the backend's auto-upvote through `HomeStore`). `feed/feed-link-card.component.ts` +
    `feed/feed-link.util.ts` — a feed row with the www-stripped domain, title, submitter
    (`nickname || shortId`), relative time (reusing the spotting `humanizeSince` util), line-code
    badges, and `app-vote-button` with `targetType="link"`.
  - **Shell** (`f4ede6b`): `home.page.ts` + `home.page.spec.ts`. `""` is now
    `loadComponent: HomePage` with `providers: [HomeStore, LineStatusSheetService]`.
